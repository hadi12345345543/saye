SAYA Android prototype (Kotlin, no Node.js)
============================================
این نمونه با روش دستی کار می‌کند: یک گوشی میزبان می‌شود و گوشی دیگر IP میزبان و رمز را وارد می‌کند. کشف خودکار اتاق ندارد.
هر دو گوشی باید به یک Wi‑Fi متصل باشند. روی گوشی میزبان پورت TCP 45454 استفاده می‌شود.
محدودیت‌های فعلی: نمونهٔ اولیه و آزمایش‌نشده؛ فعلاً چت متنی پایه دارد. ارسال فایل، حذف خودکار ۶۰ دقیقه‌ای و تماس صوتی/تصویری هنوز پیاده‌سازی نشده‌اند.

ساخت APK با GitHub Actions:
1) محتوای ZIP را استخراج کن.
2) در GitHub یک repository جدید بساز.
3) فایل‌ها و پوشه‌های داخل پروژه را در ریشهٔ repository آپلود کن (خود پوشهٔ SAYA-Android را به‌صورت تو در تو قرار نده).
4) به Actions برو و Build SAYA APK را اجرا کن.
5) در پایان اجرا، از Artifacts فایل SAYA-debug-apk را دانلود کن.
